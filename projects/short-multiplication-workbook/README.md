# חוברת נוסחאות הכפל המקוצר

זהו אזור המקור הקבוע של החוברת לפני שילובה בדפים הקנוניים של Parabola Next.

## כלל קבוע לעמוד הראשון

- שלוש נוסחאות הכפל המקוצר נכתבות רק באמצעות האותיות `a` ו-`b`.
- כל נוסחה מופיעה בשורה נפרדת.
- אין לסדר את הנוסחאות זו לצד זו משמאל לימין.
- בכל שינוי עתידי בחוברת יש לעדכן את המקור בענף זה בריפו ולא להשאיר שינוי רק בקובץ מקומי.

## קבצים

- `page-1-formulas.html` - שלוש הנוסחאות המתוקנות.
- `page-1-layout.css` - פריסה אנכית וקומפקטית שמונעת גלישה מעמוד A4.

## סטטוס

המקור נשמר בריפו `yanivmizrachiy/parabula-next` בענף `agent/short-multiplication-workbook`.
החוברת עדיין אינה ממוזגת ל-`main`, משום שמספרי העמודים הקנוניים חייבים להיקבע מחדש מול מצב הריפו העדכני.
