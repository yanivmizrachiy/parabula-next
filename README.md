# Parabula Next — דפי עבודה במתמטיקה A4

מערכת ליצירה, ניהול, קריאה והדפסה של דפי עבודה במתמטיקה בעברית RTL, עם קורא מחשב, אפליקציית נייד ו־PWA.

**האתר החי:** https://yanivmizrachiy.github.io/razpages/

## מקור הכללים היחיד

לפני כל שינוי בריפו יש לקרוא את [`CLAUDE.md`](./CLAUDE.md) במלואו. הוא המקור היחיד לדרישות, ארכיטקטורה, מובייל, A4, בדיקות ודרך העבודה.

מצב המוצר, מספר הדפים והנושאים נגזרים בזמן אמת מ־`meta/topics.json`, מהקוד ומ־GitHub Actions; הם אינם נשמרים במסמך זה.

## פקודות
