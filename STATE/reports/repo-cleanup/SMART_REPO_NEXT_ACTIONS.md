# SMART_REPO_NEXT_ACTIONS

## מטרת ההמשך

להמשיך לשפר את הריפו רק במה שבאמת צריך, בלי לשבור דפי A4, בלי לערבב נושאים, ובלי למחוק קבצים לפני audit אמיתי.

## מה כבר מיוצב

- `PROJECT_RULES.md` עודכן כך שישקף טוב יותר את מצב `main`.
- חוויית המוצר מוגדרת כ-Topic First.
- `preview/all-pages.*` מוגדר כמסך עזר חי, לא כמסך הבית הראשי.
- ערבוב נושאים נאסר במפורש.
- מחיקה / מיזוג / העברת דפים נאסרו בלי אישור מפורש.

## ממצא קריטי חדש

נמצא ערבוב אמיתי ב-`meta/topics.json`:
הנושא `משוואות` כולל בפועל דפים שכותרותיהם / תוכנם הם `משוואה ריבועית`.
זה אומר שהפרדה נושאית עדיין לא אמינה מספיק.
זה הופך את תיקון ה-metadata למשימת ההמשך החשובה ביותר.

## סדר פעולות נכון מעכשיו

### 1. תיקון מוגן של metadata נושאי
זה הצעד הבא החשוב ביותר.
אבל אסור לבצע אותו בצורה אגרסיבית או אוטומטית עיוורת.
צריך קודם:
- למפות אילו דפים בתוך `meta/topics.json` מסווגים תחת `משוואות` אבל בפועל שייכים ל-`משוואה ריבועית` / `משוואות ריבועיות`
- לקבוע שם נושא יעד מדויק לפי דרישות המשתמש
- לעדכן את ה-metadata בזהירות בלי למחוק דפים ובלי לשנות תוכן דפים
- לתעד את ההחלטה גם ב-`PROJECT_RULES.md`

### 2. כפילויות / legacy ב-preview
לבדוק אם הקבצים הבאים עדיין נחוצים, בלי למחוק עדיין:
- `preview/phone.*`
- `preview/print-center.js`
- קבצי עזר ישנים סביב install / phone / print

### 3. סנכרון כללים מול קוד
לבדוק שאין פער בין `PROJECT_RULES.md` לבין:
- `preview/topics.*`
- `preview/all-pages.*`
- `preview/print.*`
- `meta/topics.json`

### 4. קבצים מרכזיים ארוכים מדי
לבדוק בהמשך אם צריך refactor זהיר ל:
- `preview/topics.js`
- `preview/all-pages.js`
- `preview/print.js`
- `mobile-app.js`

### 5. backup/state sprawl
לבדוק האם תיקיות backup שנוצרו בזמן תיקונים צריכות להישאר כעדות היסטורית או לעבור בעתיד לאזור ארכיון מסודר יותר.
אין למחוק אותן עכשיו.

## מדיניות בטוחה

- קודם audit, אחר כך החלטה.
- לא מוחקים עכשיו.
- לא ממזגים נושאים.
- לא משנים שיוך של דפים בלי החלטה מפורשת ומתועדת.
- לא מוסיפים דמו.
- כל שינוי מבני אמיתי חייב להיכנס גם ל-`PROJECT_RULES.md`.
- תיקון metadata נושאי הוא משימה מוגנת.

## הצעד החכם הבא

למפות באופן מדויק את כל הדפים ב-`meta/topics.json` שנמצאים תחת `משוואות` אבל נראים בפועל כ-`משוואה ריבועית`, ואז להכין תיקון metadata ממוקד בלבד — בלי לגעת עדיין בדפי ה-A4 עצמם.
