# רביע ראשון

חוברת מודפסת לכיתה ז׳ בנושא מערכת צירים ברביע הראשון ובחלקים הלא־שליליים של הצירים.

## הגרסה הפעילה

- `רביע-ראשון.html` — דף הכניסה הציבורי הקבוע.
- `assets/first-quadrant/source-v2-00.b64` עד `source-v2-04.b64` — מקור HTML מלא, דחוס ב־gzip ומחולק לחמישה חלקי Base64.
- הגרסה הפעילה כוללת **19 דפי A4**, **103 כרטיסי שאלות** ו־**31 שרטוטי SVG וקטוריים**.

## מה נשמר מהגרסה המקורית

- כל 15 הדפים המקוריים נשמרו ללא מחיקת שאלות.
- הקבצים `source-00.b64` עד `source-04.b64` נשמרים בריפו כארכיון גרסה 1 ואינם נטענים עוד בדף הציבורי.

## ארבעת דפי ההרחבה

16. בחירה בין שרטוטים דומים ומעבר בין ייצוגים.
17. מרחקים אופקיים ואנכיים וניתוח טעות חישובית.
18. מעבר מכלל לטבלה ולגרף תוך שמירה על תחום הרביע הראשון.
19. מפת פארק: פירוש נקודות, מסלולים, מרחקים והצבת מתקנים.

## בדיקות

- `layout-audit-v2.json` — בדיקות פריסה, חפיפות וגלישה.
- `repo-audit-v2.json` — ספירת עמודים, שאלות, SVG וכותרות תחתונות.
- `pdf-inspect-v2.txt` — בדיקת PDF בן 19 עמודי A4.
- `manifest-v2.sha256.json` — טביעות SHA-256 של קובצי הגרסה הפעילה.

## כותרת תחתונה קבועה

## חוזה תחזוקה

- אין למחוק או לשנות שאלות קיימות ללא בקשה מפורשת.
- מוסיפים עמודים רק כאשר הם משלימים חסר פדגוגי ממשי.
- כל שינוי נעשה בענף ייעודי, עובר בדיקות מלאות ומתמזג ל־`main` רק לאחר הצלחה.
