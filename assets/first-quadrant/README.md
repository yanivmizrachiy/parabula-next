# רביע ראשון — גרסה 3

חוברת מודפסת לכיתה ז׳ בנושא מערכת הצירים ברביע הראשון ובחלקים הלא־שליליים של הצירים.

## הגרסה הפעילה

- `רביע-ראשון.html` — דף הכניסה הציבורי הקבוע.
- `source-v3-00.b64` עד `source-v3-05.b64` — תוצר HTML מלא, דחוס באופן דטרמיניסטי ומחולק לחלקים לצורך טעינה אמינה ב-GitHub Pages.
- `מפתח-תשובות-רביע-ראשון.html` — מפתח תשובות נפרד למורה.
- הגרסה הפעילה כוללת **21 דפי תלמיד**, **7 דפי פתרונות**, **107 כרטיסי שאלות** ו־**31 שרטוטי SVG וקטוריים**.
- גרסאות 1 ו־2 נשמרות בריפו כארכיון ואינן נטענות בדף הציבורי.

## תיקוני עומק בגרסה 3

- סידור מחדש של הרצף הפדגוגי: מעבר בין ייצוגים ומרחקים הוקדמו לפני השימוש בהם.
- פיצול עמוד ההשוואות לשני עמודים: חיבור/חיסור לעומת כפל/מחצית.
- פיצול עמוד תיקון הטעויות מעמוד תמיד/לפעמים/לעולם לא.
- תיקון כלל `y=2x` כך שכל הנקודות הנדרשות ניתנות לסימון בתחום.
- מיון חד־משמעי של נקודות על הצירים וראשית הצירים.
- תיקון שאלת מפת הפארק כך שתבקש את כל הזוגות בעלי אותו שיעור y.
- ניסוח מדויק של נקודה בתוך מלבן, יחידות אורך ויחידות ריבועיות.
- הבהרה שבמשימות כללים מסמנים נקודות שלמות בלבד ואין צורך לחברן.
- הוספת מפתח תשובות מלא למורה.

## בדיקות

- 21 עמודי A4 לתלמיד ו־7 עמודי A4 למורה.
- בדיקות Playwright במצב מסך והדפסה.
- בדיקות גלישה, חפיפות, SVG, תיבות תשובה וכותרות תחתונות.
- רינדור חזותי של כל 28 העמודים.
- טביעות SHA-256 ותיעוד ספירות ב־`manifest-v3.json` וב־`audit-v3.json`.
