# רביע ראשון — גרסה 3

חוברת מודפסת לכיתה ז׳ בנושא מערכת הצירים ברביע הראשון ובחלקים הלא־שליליים של הצירים.

## הגרסה הפעילה

- `רביע-ראשון.html` — דף הכניסה הציבורי הקבוע.
- `source-v3-00.b64` ואילך — תוצר HTML מלא, דחוס באופן דטרמיניסטי ומחולק לחלקים לצורך טעינה אמינה ב-GitHub Pages.
- `מפתח-תשובות-רביע-ראשון.html` — מפתח תשובות נפרד למורה.
- 21 דפי תלמיד, 7 דפי פתרונות, 107 כרטיסי שאלות ו-31 שרטוטי SVG.
- גרסאות 1 ו-2 נשמרות כארכיון ואינן נטענות בדף הציבורי.

## תיקוני עומק בגרסה 3

- רצף פדגוגי חדש: מעבר בין ייצוגים ומרחקים לפני הגאומטריה.
- פיצול השוואות חיבוריות והשוואות כפליות.
- פיצול תיקון טעויות מטענות תמיד/לפעמים/לעולם לא.
- תיקון `y=2x` כך שכל נקודה נדרשת נמצאת בתחום.
- מיון חד־משמעי של נקודות על הצירים וראשית הצירים.
- כל זוגות המקומות בעלי אותו שיעור y במפת הפארק.
- ניסוח מדויק של פנים מלבן, יחידות ויחידות ריבועיות.
- נקודות שלמות בלבד במשימות כלל-טבלה-גרף.
- מפתח תשובות מלא למורה.
