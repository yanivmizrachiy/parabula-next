# מערכת משוואות בשני נעלמים — אפליקציה, אוטומציה ובקרת איכות

הפרק מנוהל כחוברת רציפה שמתחילה בעמוד `609` ומסתיימת בעמוד `616`.

## אפליקציית הצפייה

הקובץ `systems-workbook.html` הוא מעטפת נפרדת שאינה משנה את עיצוב דפי העבודה. היא טוענת את הדפים המקוריים ומספקת:

- מעבר קדימה ואחורה.
- בחירת עמוד מהירה ורשימת תוכן מלאה.
- החלקה בטלפון וקיצורי מקלדת במחשב.
- שמירת העמוד האחרון במכשיר.
- קישור ישיר לכל עמוד, העתקת קישור והדפסת הדף הנוכחי.
- תצוגה רספונסיבית, מסך מלא והתאמות נגישות.

האפליקציה קוראת את הנתונים מ־`meta/two-variable-systems-manifest.json`, ולכן אינה מחזיקה רשימת דפים כפולה שעלולה להתיישן.

## פקודות עבודה

- `npm run systems:audit` — מציג את מצב החוברת: מספר דפים, מספר משימות, סדר הדפים וחלוקה לפי סוגי משימות.
- `npm run systems:manifest:check` — מוודא שה־manifest תואם למצב בפועל.
- `npm run systems:manifest:write` — מעדכן את ה־manifest לאחר שינוי מכוון בתוכן או בסדר הדפים.
- `npm run systems:ci` — מפעיל את כל בדיקות החוזה הייעודיות לפרק ולאפליקציית הצפייה.

## מה נבדק אוטומטית

1. שרשרת הניווט בין כל דפי החוברת, כולל העמוד שלפניה והעמוד שאחריה.
2. מיקום כל דף בתוך החוברת והמספור המודפס.
3. קיום כותרת הנושא וקישור פעיל לעמוד הפתיחה.
4. קיום קובץ CSS לכל דף וייבוא שכבת העיצוב המשותפת.
5. מספר המשימות בכל דף והחלוקה למערכות, בעיות מילוליות, מיון פתרונות, אתגרים וחשיבה מתמטית.
6. התאמה בין סדר הדפים בפועל לבין `meta/systems-drive-sync.json`.
7. התאמה מלאה ל־`meta/two-variable-systems-manifest.json`.
8. קיום רכיבי הניווט, ההדפסה, ההחלקה, המקלדת והנגישות באפליקציית הצפייה.

כל שינוי שמשפיע על הפרק או על אפליקציית הצפייה מפעיל workflow ייעודי ב־GitHub Actions.
