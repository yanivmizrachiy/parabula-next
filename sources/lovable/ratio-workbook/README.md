# ⛔ יחס ופרופורציה — ארכיון היסטורי בלבד

**התיקייה הזאת אינה מקור אמת, אינה סביבת פיתוח ואסור לבצע ממנה שינוי, build, Preview או פרסום.**

פרויקט היחס עבר במלואו לריפו העצמאי:

`yanivmizrachiy/ratio-workbook`

מקור הדרישות היחיד והמחייב נמצא שם בקובץ:

`SOURCE_OF_TRUTH.md`

## סטטוס

- מקור הקוד הפעיל של יחס הועבר לריפו העצמאי.
- 55 דפי תלמיד עברו ונבדקו שם.
- דפי המורה אינם חלק מחוברת התלמיד.
- המספור מתחיל בעמוד 1.
- ה-build, ה-tests, ה-Preview, ה-PDF ובדיקות A4/Chromium פועלים מתוך הריפו העצמאי בלבד.
- פקודות ה-`ratio:*`, סקריפטי ה-import/render/audit וה-CI של Ratio הוסרו משורש `razpages`.

## למה התיקייה עדיין קיימת?

רק לשם היסטוריה ו-rollback במקרה חריג. היא **מוקפאת** ואינה חלק מזרימת העבודה הפעילה.

כל שינוי עתידי בנושא יחס נעשה אך ורק ב-`yanivmizrachiy/ratio-workbook`, ורק לאחר עדכון `SOURCE_OF_TRUTH.md` כאשר מדובר בדרישה חדשה.
