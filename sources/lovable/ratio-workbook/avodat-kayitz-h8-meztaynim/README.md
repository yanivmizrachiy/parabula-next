## קרדיט

## נושא ראשון

- שיפוע
- חיתוך עם ציר y
- חיתוך עם ציר x

- טבלאות ערכים
- התאמת גרף למשוואה
- נקודת חיתוך בין ישרים
- בעיה מילולית עם מודל קווי
