# תוכנית ומצב — חוברת „יחס”

מסמך זה מתעד **מצב עבודה ותוכנית ביצוע בלבד**. הוא אינו מקור כללים. כל ההוראות המחייבות נמצאות רק ב־`CLAUDE.md` בשורש הריפו.

## תחום החוברת

- מקור תוכן ועריכה: `sources/lovable/ratio-workbook/src/`.
- 48 דפים מקומיים: 1–48.
- דפים קנוניים באתר: `עמוד-272.html` עד `עמוד-319.html`.
- תמונות `assets/ratio/page-001.png` עד `page-048.png` משמשות visual baseline ותוצר רינדור; הן אינן מקור לעריכת תוכן.

## מצב נוכחי בענף השיפור

### מקור ותוכן

- מפת 48 העמודים קיימת ב־`src/data/worksheetPages.tsx`.
- קיימות בדיקות מבנה ומתמטיקה ב־`src/test/`.
- נוסף מבנה תשובה מפורש לשאלות יחס, חישוב, הסבר וזוג סדור.
- שופרו מבני מענה בדפים צפופים בלי החלפת נתונים מתמטיים או יצירת שאלות חדשות.
- ביקורת patch מול `main` של קבצי התוכן ששונו לא מצאה שינוי במספרי השאלות או בנתונים המתמטיים; שינויים מילוליים שנעשו הם בכותרות ניווט/פרק ובסילוק תוויות דמו.

### מיפוי ו־manifest

- קיים `generate-content-manifest.mjs` עם מצב check-only ומצב write מפורש.
- בדיקת manifest מכסה 48 עמודי מקור סמנטיים.
- `content-manifest.json` אינו שמור כרגע כתוצר קנוני בריפו; לכן מיפוי מקור חיצוני ואישור מקור מלא לכל שאלה עדיין אינו מסומן כהושלם.

### מעבר ל־HTML חי

- קיים `scripts/export-ratio-workbook-live.mjs` שמפיק מועמדי HTML קנוניים מתוך מקור ה־React.
- ברירת המחדל של ה־exporter היא preflight ללא כתיבה.
- ה־preflight בודק את כל 48 המועמדים מבחינת A4, overflow, footer, מבנה DOM, תלות ב־full-page PNG ושגיאות דפדפן לפני אפשרות כתיבה.
- נוסף scope קבוע `ratio-page-N` לכל עמוד כדי לאפשר התאמות נקודתיות ללא השפעה על דפים אחרים.
- לחמשת הדפים שנכשלו ב־preflight הקודם — 1, 16, 18, 21 ו־48 — נוספה שכבת fit ממוקדת שאינה מקטינה גופן, אינה עושה scale ואינה מסתירה overflow.
- semantic canonical preflight עדכני עבר 48/48.
- `עמוד-272.html` עד `עמוד-319.html` נכתבו בענף כ־HTML חי מתוך מקור ה־React לאחר מעבר כל שערי ה־preflight.
- קובצי ה־PNG נשארים תוצרי רינדור/visual baseline בלבד ואינם מסלול הכתיבה הקנוני.

### הגנת שאר האתר

- `scripts/check-ratio-change-scope.mjs` מגביל את תחום שינויי היחס.
- workflow היחס מכוון במפורש רק ל־272–319 ולמסלולי ratio.
- בדיקות חוזה אוסרות הרחבת trigger לכל `עמוד-*.html` או לכל CSS של דפי האתר.
- ה־exporter אינו רושם כיעדי כתיבה את `meta/topics.json`,‏ `styles/a4-base.css`, הקוראים או קבצי mobile.
- ה־importer ההיסטורי של PNG נשאר זמין ל־preflight בלבד; כתיבה במסלול הישן נחסמת כאשר ה־exporter הסמנטי קיים.
- materialization מתבצע רק לאחר verify ירוק, ב־job נפרד ומוגבל לענף היחס; ה־verify עצמו נשאר read-only.
- guard של קבצים staged קורא נתיבי Git ב־NUL-delimited mode כדי לשמור שמות עבריים בדיוק ולא לעקוף או לשבור את allowlist.

## מה עדיין לא הושלם

- אימות מלא נוסף של **התוצר הקנוני שכבר נכתב**: חוזי ריפו, mobile, print/PDF וביקורת חזותית על ה־head הנוכחי.
- מיפוי ואישור מקור חיצוני מלא לכל שאלה, אם נדרש לצורך הצהרת התאמה מלאה.
- הסרת שאריות מסלול PNG קנוני ישן תבוצע רק אם לאחר האימות הסופי יימצא שהן אינן נדרשות עוד ואינן referenced; אין למחוק baseline נגזר רק לשם ניקוי.

## סדר ההמשך

1. להריץ שוב על ה־head הקנוני את כל בדיקות מקור היחס, semantic SSR ו־manifest.
2. לרנדר ולאמת שוב 48/48 A4 ואת 48/48 semantic canonical pages.
3. להריץ `ci:all` ואת בדיקות mobile על התוצרים שכבר נכתבו.
4. לוודא שתוצרי ה־PNG הנגזרים תואמים למקור ואין stale renders.
5. לבדוק שה־diff הסופי מול `main` מוגבל למשטח היחס בלבד.
6. לעדכן את מצב ה־PR לעובדות הסופיות.
7. רק לאחר כל אלה לאשר מיזוג ל־`main`.
